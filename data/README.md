# Dados

Esta pasta contém somente instruções e referências sobre os dados do projeto.

Não versionar datasets grandes ou arquivos contendo credenciais. Os dados devem ser obtidos das fontes públicas documentadas e armazenados conforme a estratégia de ingestão definida nas próximas tarefas.

Para cada fonte, registrar quando aplicável:

- origem ou URL oficial;
- data de coleta;
- período de referência;
- nome do arquivo;
- hash do arquivo;
- limitações de uso e cobertura.
